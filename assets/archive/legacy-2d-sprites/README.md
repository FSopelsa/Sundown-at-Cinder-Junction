# Legacy 2D Sprite Archive

These files supported the retired Phaser/isometric presentation. They are not
loaded by the Three.js runtime and must not be copied to `public/assets/` as
part of ordinary 3D work.

Some `base_images/` files are web-sourced visual references with verified
licensing. Keep them mostly as historical reference, but can be used as insporaton and perhaps
when/if possible for texture-map, or to train a generation service on them (but always ask before doing this).

The active art contract is in `AGENTS.md`; current Blender sources live in
`assets/blender/` and runtime GLBs live in `public/assets/models/`.
