# Cinder Threshold room package

This package is the review record for the first 3D milestone.

The shipped GLBs are functional navigation-and-composition blockouts for
Arrival Yard and Relay Hall. They prove room alignment, the open Arrival Gate,
3D pointer conversion, and gameplay-scale placement. They are not approved
final art.

`milestone-reviews.json` intentionally remains `pending`: the next step is to
author the room brief, floor plan, opening schedule, material reference, and
review renders with a human art-direction decision. Only after that approval
should the Blender scene be treated as an environment-art source rather than a
technical prototype.

The editable source and deterministic export script are in
[`assets/blender/`](../../../assets/blender/).
