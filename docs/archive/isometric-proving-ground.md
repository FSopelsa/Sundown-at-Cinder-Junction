# Archived reference: `prel/isometric-proving-ground`

`prel/isometric-proving-ground` is the original Phaser/isometric proof of
concept. Its useful gameplay exploration informed the current prototype, but
the active game has moved to a Three.js room-based renderer with a serializable
simulation and DOM HUD.

Do not add features, fix bugs, or use it as a merge source. Keep it only when a
historical comparison helps answer a specific question. A future repository
cleanup can delete the remote branch after the preserved history is no longer
valuable; that decision is intentionally separate from day-to-day development.
